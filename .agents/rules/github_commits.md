# GitHub Commits & Workflow Notes

Whenever you push and commit code to GitHub for the Period Tracker project, you MUST follow these guidelines:

1. **Commit Messages**: Format all commit messages using the Conventional Commits style (e.g., `feat: cc billing cycles...`, `style: configure two-column layout...`, `fix: sign-in overlay...`).
2. **Workflow Notes**: After pushing, you MUST explicitly provide the user with clear "workflow notes" in your response. These notes should list the updates just like they appear on the GitHub Actions Workflow page, using the exact commit message text and a visual checkmark (✅).

Example response format:
"I have pushed the following updates to GitHub:
✅ feat: cc billing cycles and credit limit monitoring
✅ fix: sign-in overlay deadlock and change first-tap listener to click"
